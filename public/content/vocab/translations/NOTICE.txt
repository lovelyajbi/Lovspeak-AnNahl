LovSpeak static English-Indonesian vocabulary index

This compact, per-letter index is used only for words present in LovSpeak's
authored Reading and Listening libraries. LovSpeak's manually curated entries
take priority over imported lexical candidates.

Lexical data sources:

1. FreeDict English-Indonesian dictionary, version 2025.11.23
   https://freedict.org/downloads/
   Generated by WikDict from Wiktionary/DBnary data.

2. word2word English-Indonesian bilingual lexicon
   https://github.com/kakaobrain/word2word

   Software/data package license: Apache License 2.0.
